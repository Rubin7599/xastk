# Fit templates (draft format)

Templates pin the choices a lab agrees on (S0² source, windows, constraints, required checks) so
that two analysts fitting the same spectrum make the same hidden choices. The **format is a draft**:
the template engine that reads these files is scheduled for Phase 2 (technical report §7, §9).
Until then they serve as a written lab standard and as the target format for review.

| Template | Use |
| --- | --- |
| `fcc_metal_first_shell.yaml` | metal foils and nanoparticles, first M–M shell, optional C3 |
| `sac_MN4_first_shell.yaml` | single-atom M–N₄ sites with second-shell C, model-set comparison |
